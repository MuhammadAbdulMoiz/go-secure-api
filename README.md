# go-jwt-auth-starter

A clean and modular starter project demonstrating **JWT-based authentication** in **Golang**, using:

- **Gin-Gonic** as the HTTP web framework
- **MongoDB** as the database
- **bcrypt** for secure password hashing
- **JWT** for token-based authentication and route protection

This project implements user **registration**, **login**, and **protected routes** using middleware to verify tokens.
